# 拾光 · 手动验收清单

## 启动

- [ ] 使用任意静态服务器打开根目录 `index.html`。
- [ ] 页面能加载 `src/styles/main.css` 与 `src/app.js`，无资源 404。

## 核心流程

- [ ] 活动列表能显示 26 条活动数据中的前 6 条。
- [ ] 搜索活动标题、地点或来源时，列表结果会实时变化。
- [ ] 类型筛选与侧边栏快速筛选可以使用。
- [ ] 点击活动详情能打开抽屉，并显示时间、地点和来源。
- [ ] 收藏与提醒操作会弹出反馈提示。

## 状态与响应式

- [ ] 收藏状态刷新页面后仍然保留。
- [ ] 提醒状态刷新页面后仍然保留。
- [ ] 在桌面、平板和手机宽度下检查布局，没有横向溢出。
