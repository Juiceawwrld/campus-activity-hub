# 拾光 · 校园活动中心

一个面向大学生的校园活动信息工作台，将学院通知、社团活动、竞赛招募和学习资源统一整理为可检索、可筛选、可收藏、可提醒的界面。

## 运行方式

直接用浏览器打开 `index.html` 即可预览，也可以在当前目录启动任意静态文件服务器。

## 项目结构

```text
.
├─ index.html                 # 静态入口
├─ src/
│  ├─ app.js                  # 活动数据、筛选、收藏、详情抽屉与提醒逻辑
│  └─ styles/
│     └─ main.css             # 页面视觉系统与响应式布局
├─ tests/
│  └─ manual-checklist.md     # 启动、流程、状态和响应式验收清单
├─ .gitignore
└─ README.md
```

## 已实现功能

- 从题目给出的校园活动表整理出 26 条活动数据
- 活动关键词搜索、活动类型筛选、收藏 / 取消收藏
- 活动详情侧边抽屉、加入提醒反馈、概览与收藏视图切换
- 收藏和提醒状态持久化到浏览器 `localStorage`
- 桌面端优先的 Apple 风格视觉系统，并兼容窄屏布局
- 对“时间待确认 / 信息不完整”的条目保留不确定状态，不擅自补全信息

## 验收

请按 [`tests/manual-checklist.md`](tests/manual-checklist.md) 检查资源加载、核心流程、状态保存和响应式布局。
